# Europa teams

Europa teams is a website that gives you a detailed view to the teams whom are competing in the UEFA Women's Europa League.

## Features

- lists all teams from the supplied 'data.php' file
- Displays each team's logo, city, domestic league and UEFA coefficient ranking
- Includes an About page about the creator and what type of website it is
- uses responsive css styling

## built with

- PHP
- HTML
- CSS

## Run locally

1. clone this repository.
2. Open the project folder in terminal.
3. Start the PHP development server by running php -S localhost:8000
4. open http://localhost:8000 in your browser.
